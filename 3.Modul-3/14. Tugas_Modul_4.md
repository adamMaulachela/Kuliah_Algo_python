# Sistem Generator Slip Gaji & ID Karyawan Otomatis

**Skenario**: Anda adalah seorang programmer junior di sebuah perusahaan startup. HRD meminta Anda membuat program sederhana untuk karyawan baru. Program ini harus bisa:

1. Menerima input data diri karyawan.

2. Memanipulasi nama untuk membuat User ID unik.

3. Menghitung umur berdasarkan tahun lahir.

4. Menghitung estimasi gaji bersih setelah tunjangan dan potongan pajak.

5. Mengecek apakah karyawan berhak mendapatkan "Bonus Tech" (berdasarkan kriteria logika tertentu).

6. Mencetak slip gaji rapi dengan tanggal hari ini.

**Tugas Anda :**

1. Buat program python dari kasus ini, dan tampilkan outputnya (Di Print)
2. Buat penjelasan kode yang anda buat baris per baris (Tulis Tangan)
3. Buat Flowchartnya (Tulis Tangan)
